# Amirmohammad Ebrahimi

Academic website: https://ebrahimiamir.github.io/

Static HTML and CSS. No build step or JavaScript is required.

## Content

- Home: biography and talks
- Research: publications and working papers
- Teaching: courses and undergraduate mentorship
- Background: education, grants, awards, and service

The website includes no CV file or CV download link.

## Updating

Edit the HTML files to update the content, and styles.css to update the layout. The portrait and favicon are in assets/. Keep the CV outside this repository.

## Local preview

Run `python3 -m http.server 8765` in this directory and visit http://localhost:8765/.

## Hosting

GitHub Pages serves the main branch from the repository root. The .nojekyll file enables direct static-file hosting.
